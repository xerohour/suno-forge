## 2024-05-18 - Keyboard Accessibility for Nested Interactive Elements
**Learning:** When adding keyboard accessibility (role="button", tabIndex={0}, onKeyDown) to a custom wrapper element (like a dropzone div), if that wrapper contains a visual button element, leaving it as a `<button>` creates an invalid nested interactive element structure.
**Action:** Convert the inner `<button>` to a `<span>`. To maintain the original visual hover effects on that inner element when the outer wrapper is hovered, apply the `group` class to the outer wrapper and change the inner element's hover utilities (e.g., `hover:scale-105`) to `group-hover:scale-105`.
