## 2025-02-23 - Interactive Custom Dropzones Need Full Keyboard Support
**Learning:** Custom interactive elements (e.g., clickable divs acting as dropzones) used for file uploads often lack basic keyboard accessibility and can introduce invalid HTML semantics if they nest a button tag inside the clickable container.
**Action:** Always add `role="button"`, `tabIndex={0}`, an `onKeyDown` handler that triggers on 'Enter' and 'Space', and corresponding `focus-visible` utility classes to custom interactive containers. Replace any nested `<button>` elements with styled `<span>` elements using `inline-block` to preserve layout without violating HTML semantics.
